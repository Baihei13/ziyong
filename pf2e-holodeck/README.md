# PF2e Holodeck（简体中文汉化）

基于 [kerplunk177/pf2e-holodeck](https://github.com/kerplunk177/pf2e-holodeck) v4.1 的中文汉化版。

## 安装

把本目录 `pf2e-holodeck` 复制到 Foundry 的 `Data/modules/` 下，启用模组，并将 Foundry 界面语言设为 **简体中文（zh-Hans）**。

## 说明

- 模组 ID 仍为 `pf2e-holodeck`，与原版兼容。
- 危险室 HUD、战斗取证面板主要 UI、通知与快捷键已汉化。
- 部分动态生成的战斗日志细节可能仍显示英文（来自解析器内部标签）。
