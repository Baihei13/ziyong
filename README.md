# 自己用的 Mod

## 模组

| 目录 | 说明 |
|------|------|
| `pf2e-holodeck` | 原版 PF2e Holodeck 4.1（官方上游备份，勿与汉化混改） |
| `pf2e-holodeck-zh` | 独立简体中文汉化层（需同时启用原版） |

## 安装清单

**原版 Holodeck：**
https://raw.githubusercontent.com/Baihei13/ziyong/main/pf2e-holodeck/module.json

**简体中文：**
https://raw.githubusercontent.com/Baihei13/ziyong/main/pf2e-holodeck-zh/module.json

## 用法

1. 安装并启用 `PF2e Holodeck`
2. 安装并启用 `PF2e Holodeck 简体中文`
3. 刷新页面

上游原版：https://github.com/kerplunk177/pf2e-holodeck
